# Histórico de alterações

Todas as alterações relevantes do VisionHub serão documentadas neste arquivo.
O projeto utiliza [Versionamento Semântico](https://semver.org/lang/pt-BR/).

## [Não publicado]

## [1.1.0-beta.3] - 2026-08-05

### Adicionado

- Tela de apresentação exibida na janela principal durante a inicialização.
- Ícones personalizados para os aplicativos e instaladores de cada sistema.
- Guias para builds locais e publicação de novas releases.
- Imagem de apresentação na página inicial do projeto.

### Alterado

- Builds de Windows e macOS agora incorporam a imagem de apresentação.
- Pacote Linux documentado com ícones e lançador para o menu de aplicativos.

## [1.1.0-beta.2] - 2026-08-04

### Corrigido

- Publicação automática dos instaladores na GitHub Release.
- Compatibilidade das actions com o runtime Node.js 24.

## [1.1.0-beta.1] - 2026-08-04

### Adicionado

- Mosaicos configuráveis para quatro ou oito câmeras.
- Nomes personalizados para os canais.
- Assistente de configuração inicial com armazenamento seguro da senha.
- Instaladores para Windows 11 e macOS.

### Alterado

- Visualização ajustada para preservar data e hora presentes no vídeo.
- Tentativas de conexão limitadas antes de exibir “Sem conexão”.
